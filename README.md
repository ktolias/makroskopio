# ΜΑΚΡΟΣΚΟΠΙΟ · EU-27 Macro Observatory

Διαδραστική web-εφαρμογή που παρουσιάζει μια μελέτη αναλυτικής δεδομένων πάνω σε τέσσερις θεμελιώδεις
μακροοικονομικούς δείκτες των **27 κρατών-μελών της ΕΕ** για την περίοδο **2000–2024**:

- **Κατά κεφαλήν ΑΕΠ** (PPP, σταθερά $ 2021)
- **Προσδόκιμο ζωής** στη γέννηση
- **Εκπομπές CO₂** ανά κάτοικο
- **Ποσοστό ανεργίας**

> Εργασία για το μάθημα «Δεδομένα Μεγάλης Κλίμακας & Επιχειρηματική Αναλυτική»,
> Π.Μ.Σ. Διοίκηση Έργων, Πανεπιστήμιο Πειραιώς.

## Πηγή δεδομένων

World Bank — **World Development Indicators (WDI)** · 675 παρατηρήσεις (27 × 25), μηδέν ελλιπείς τιμές.
Τα δεδομένα είναι ενσωματωμένα στο `src/data/dataset.ts` (auto-generated από τα αρχικά Excel αρχεία).

## Τι περιλαμβάνει

| Ενότητα | Περιεχόμενο |
|---|---|
| **Αρχή** | Τίτλος, μελέτη περίπτωσης, 4 ερευνητικά ερωτήματα, KPIs |
| **Δεδομένα** | Πηγή & ορισμοί δεικτών, δομή, λήψη CSV, ταξινομήσιμος πίνακας μέσων όρων |
| **Μεθοδολογία** | 8 βήματα υλοποίησης — κάθε ένα με **Ενέργεια** και **Αιτιολόγηση** |
| **Κατανομές** | Q1 · θηκογράμματα + ιστογράμματα + πεντάριθμη σύνοψη (διαδραστική επιλογή δείκτη) |
| **Dashboard** | Διαδραστικός χάρτης-cartogram της ΕΕ με χρονικό slider & αναπαραγωγή, + διαχρονικές γραμμές ανά χώρα |
| **Συσχετίσεις** | Q2–4 · θερμικός χάρτης Pearson + απαντήσεις ανά ζεύγος |
| **Μοντέλα** | Ομάδα Α (γραμμική/πολυωνυμική/λογαριθμική παλινδρόμηση) · Ομάδα Β (κινούμενος μέσος / εκθετική εξομάλυνση) με R²/MAE/MSE |
| **Συμπεράσματα** | Εύρημα → Πρόταση ανά ερώτημα, περιορισμοί, τελικό συμπέρασμα |
| **AI** | Κεφάλαιο διαφάνειας για τη χρήση Generative AI |

Όλες οι αναλύσεις (κατανομές, συσχετίσεις, παλινδρομήσεις) **υπολογίζονται ζωντανά** από τα δεδομένα στο
`src/lib/stats.ts` και έχουν επαληθευτεί ότι συμφωνούν με τα νούμερα του Excel workbook.

## Τεχνολογίες

React 18 · TypeScript · Vite · Recharts · Framer Motion. Light/Dark theme, πλήρως responsive.

## Εκτέλεση

```bash
npm install
npm run dev      # http://localhost:5174
npm run build    # production build στο dist/
npm run preview  # σερβίρει το dist/ — εδώ ενεργοποιείται το PWA (service worker)
```

## PWA — εγκατάσταση στο κινητό

Η εφαρμογή είναι **Progressive Web App**: εγκαθίσταται στην αρχική οθόνη, ανοίγει χωρίς
μπάρα διεύθυνσης (standalone) και δουλεύει **offline** (precache ~1,35 MB). Το service worker
και το manifest ενεργοποιούνται μόνο στο production build (`npm run preview`, όχι `npm run dev`).

- **iOS (Safari):** Κοινή χρήση → «Προσθήκη στην αρχική οθόνη».
- **Android (Chrome):** μενού ⋮ → «Εγκατάσταση εφαρμογής» (ή το auto-prompt).
- **Desktop (Chrome/Edge):** εικονίδιο εγκατάστασης στη γραμμή διεύθυνσης.

Για δημόσια πρόσβαση από κινητό χρειάζεται **HTTPS** (π.χ. ανέβασμα του `dist/` σε
Netlify/Vercel/GitHub Pages, ή `cloudflared tunnel`). Τα PWA απαιτούν secure origin.
